# M3.1 — Simple by default, advanced on demand

Implemented behavior and acceptance record. Preserve all Audit rules/scoring, Usage discovery/resolution/classification, job processing and entitlement engines. Schema remains Core 3 / Pro 1. Changes belong to presentation, indexed read queries, navigation and diagnostics.

Primary areas: Library, Health, Usage (when entitled), Advanced (administrators). No Optimize/Cleanup placeholders. Existing header, VTX tokens and native WordPress React remain.

Usage answers where a file is used. In use + Not in use + Needs review partition media; the review collection retains Possibly used, Unknown and Broken-reference file states in detail. Broken references are a separate set of locations, not an additional media total. Every collection card resets conflicting filters and opens the same authoritative query scope. Attachment location counts include stored locations with clear stale labels. Broken-reference summary drills use current references to match the existing summary.

Locations use a single paginated detail drawer from lists, coverage and Inspector. Grouping is based on recorded provider/source types and trusted WordPress object types. Do not invent hero/section names. Technical locator, provider/version, raw confidence, IDs and exact timestamps remain collapsed. Safe actions derive from WordPress objects and a small known-settings allowlist.

Normal scan coverage is compact and optional. Detailed providers, refresh, source problems, job history, logs, rules and sanitized system/entitlement diagnostics belong in Advanced. Normal scan controls retain start/pause/resume/cancel. Failures have an explicit next action. Advanced is capability protected, not a browser-only hiding rule.

Inspector order: file facts, Health, SEO & Accessibility editing/review, Usage, Organization, contextual technical details. Future Optimization uses a real extension slot only when an installed module supplies content/actions. Legacy Inspector extensions continue to render.

Counts representing files versus findings versus locations are labeled separately. Current Health summary drills include the same signature/state scope; older findings remain available in Advanced filters. Optional captions/descriptions are explicitly optional. Decorative ALT intent and native metadata saves are unchanged.

Shared components provide technical disclosure, relative dates with exact accessible timestamps, focus-managed drawer, section navigation and pagers. Default tables preserve meaningful actions at mobile widths. Keyboard/Escape/focus return, reduced motion, contrast and four-width screenshots are acceptance checks.

Protected engine hashes, baseline/final test results, count/drill assertions, endpoint permissions and release exclusion checks are recorded under development test artifacts. M3.1 acceptance passed; exact executed checks and runtime limitations are recorded in TESTING.md. Next: M4 Image Optimization; M5 Cleanup/Duplicates; M6 AI; M7 organization/permissions/automation/analytics. Licensing remains deferred.
